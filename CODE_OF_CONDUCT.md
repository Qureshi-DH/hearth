# Code of conduct

## The short version

Be decent. This is a small project about keeping families safe, and there's no
room here for making people feel unwelcome.

## What that means

Assume good faith. Most disagreements in software are two people optimising for
different things, not one person being wrong.

Criticise code, not people. "This query will lock the table for minutes" is
useful. "This is amateur work" is not.

Harassment, personal attacks, and unwelcome attention are not tolerated, in
issues, pull requests, discussions, or anywhere else connected to the project.

This project handles location data about real families, including children. If
you find a way to misuse it, report it privately rather than demonstrating it.

## If something goes wrong

Report it to the maintainers through a private GitHub advisory or by email.
Reports are handled confidentially. Maintainers may edit or remove comments,
close issues, or ban accounts, and will say why when they do.

Maintainers who don't follow this themselves should expect to be called on it.
