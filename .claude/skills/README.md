# Project skills

Instructions for anyone, human or agent, working in this repository.

| Skill                                               | Read it when                                                                                |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [natural-writing](natural-writing/SKILL.md)         | Writing any prose. README, docs, comments, commit messages, UI copy.                        |
| [hearth-conventions](hearth-conventions/SKILL.md)   | Writing or reviewing code. Comment policy, database traps, privacy and authorisation rules. |
| [hearth-architecture](hearth-architecture/SKILL.md) | Adding a feature, or working out where existing behaviour lives.                            |

They are plain markdown, so they are useful whether or not your editor knows
what a skill is.
