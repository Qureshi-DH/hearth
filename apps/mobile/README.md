# Hearth mobile

The iOS / Android client for [Hearth](../../README.md), built with Expo SDK 55
on the Ignite boilerplate.

```bash
pnpm install            # from the repo root
npx expo prebuild       # native projects (git-ignored)
npx expo run:ios        # or run:android
```

Everything else — permissions, background location, EAS builds, project
structure, design notes — is in [docs/MOBILE.md](../../docs/MOBILE.md).
